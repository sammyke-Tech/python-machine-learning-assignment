# Part C: Theory Questions
# 1. What is supervised machine learning?
Learning from labeled data
# 2. What is unsupervised machine learning?
Discovering patterns in unlabeled data
# 3. Explain the difference between supervised and unsupervised learning.
Supervised learning uses labelled data, while unsupervised learning uses unlabelled data.
# 4. Why is Linear Regression considered supervised learning? 
Because it learns from labelled data to predict numerical values.
# 5. Why is K-Means considered unsupervised learning? 
Because it groups data based on similarities without predefined labels.
# 6. What is the difference between fit() and predict()?
The fit() method is used to train a machine learning model using data. The predict() method uses a trained model to generate predictions for input data.
# 7. Give two real-world applications of supervised learning and two of unsupervised learning.
Supervised Learning:

House price prediction: Predicting property prices based on features such as size, location, and number of rooms.

Email spam detection: Classifying emails as spam or not spam using previously labeled examples.

Unsupervised Learning:

Customer segmentation: Grouping customers based on purchasing habits and shopping behaviour.

Document clustering: Organizing similar documents into groups based on their content.
